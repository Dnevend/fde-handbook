# 测试集

两个版本并存，别混用：

| 版本 | 文件 | 题数 | 谁在用 | 说明 |
|---|---|---|---|---|
| v1 | `qa.jsonl` | 80 | 第五部分 | 已写进正文的历史数据；四类各 20，含改写答案 |
| v2 | `qa-v2.jsonl` | 300 | 第六部分 | 79 道 v1（剔除 R12）+ 221 道新题；答案逐字来自条款 |

v2 的四类各 75，**dev/test 各 150**。v1 的 79 道全部进 dev（第五部分已经用它们选过切分、维度与融合方式），
test 的 150 道全部是新题。R12「注塑工艺参数」在拒答审计中被发现可由专利 `pat-inj-02` 回答，已退役，v2 不再收录。

每行一题，字段：

| 字段 | 含义 |
|---|---|
| `id` | `D`/`C`/`X`/`R` + 两位序号；v2 续到 75（拒答到 76） |
| `category` | `direct` / `condition` / `cross` / `refuse` |
| `question` | 问题。改写成自然问法，不抄条款原文 |
| `answer` | 标准答案。v2 要求逐字来自所引条款；拒答固定为「资料中没有相关信息。」 |
| `sources` | 出处：`doc` 是语料 id，`clause` 是条款号；拒答为空 |
| `synthetic` | 是否来自合成语料；本书测试集全部为 `false` |
| `joint` | 跨段题是否需要两个出处都命中才算成功 |
| `split` | v2 专有：`dev` / `test`；v1 没有这个字段 |

## 四类怎么分

- **直接摘取（75）**：答案在一条条款里，问法换过。
- **条件判断（75）**：给场景（人数、金额、行业、频次），套用条款里的阈值或适用范围。
- **跨段组合（75）**：答案分散在两条条款，必须两段都找到（`joint: true`）。
- **拒答（75）**：语料里没有答案，正确行为是说「资料中没有相关信息」。

## 出题口径

1. 只从三份有稳定条款结构的语料出题：`reg-safety-law`、`reg-mem-order-13`、`gov-ledger-guide`。
   `gov-checklist-hs` 的编号是它引用的法条号，`gov-responsibility-zs` 按岗位分节、每节从 1 重启，同一数字指不同职责；两者只当检索干扰项。
   指南是汇编，54 个条号里 27 个重复；出处按「条号 + 答案原文」定位，6.2 的相关性按正文判，不只比条号。
2. 答案逐字抄条款，可以取连续一两句、用「；」拼接；不加「不符合」这类判断前缀。
   自动判定靠子串，改写会让「答对意思但换了词」被判错——这个偏差在 v2 里被刻意保留，6.3 再讨论。
3. 跨段题的两个出处都要在答案里留下原文，否则 `validate.py` 报错；条号在正文里重复时，答案还必须只落在其中一段不同正文里。
4. 同一 `(doc, clause)` 在新增题里、同一题型下最多 2 题；总量上限 4 题（跨段题会复用枢纽条款）。
5. 拒答题要过一遍检索审计（`labs/06-evaluation/audit_refuse.py`）：把题当查询，top-1 相似度 ≥0.65 的逐条人工看。
   75 道里标出 2 道，人工复核都不是可答；v1 的 R12 就是这样被发现的。
6. 分片规则：v1 全部 dev；新题每类取固定数量（17/18/17/19）进 dev，按题目哈希选，不人工挑。
7. 不写「第 X 条怎么规定」这类题——那是在考关键词，不是在考检索。

## 规模与局限

- 300 题里 225 道可答、75 道拒答。独立比例的分辨率只有 ±6pp 左右；真正提高功效的是**配对比较**
  （同一道题上的对错变化），6.4 用配对 bootstrap / McNemar，不拿两个独立比例硬比。
- dev 的出处 64% 来自安全生产法（因为 79 道 v1 全在 dev），test 是 46%；两侧文档组成不同。
  dev 上选出来的参数不能直接套到 test 的绝对水平，只能看相对变化。
- 一个人出题，没有标注者间一致性（κ）；6.3 用 LLM 裁判与 60 条人工标签补一部分。
- 全部是法规/政府文件文体；换到工单、手册，题型配额要重设。

## 校验

```bash
python3 eval/validate.py                 # v1 + v2：结构、出处、原文、分片
python3 eval/validate.py --draft 草稿.jsonl --category direct   # 写题时自检
python3 eval/clause_text.py --stats      # 看 raw 里能还原多少条款
```

零依赖；`corpus/raw/` 不在时，原文核对降级为提示。统计与审计产物在 `benchmarks/evaluation/`。
