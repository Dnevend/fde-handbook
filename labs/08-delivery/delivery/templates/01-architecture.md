# 架构与数据流

## 1. 系统上下文

```text
用户（Web/IM/CLI）
   │ HTTPS + SSE
   ▼
API 网关（鉴权/限流/审计）
   ▼
RAG 服务（检索 → 重排 → 生成 → 引用）
   ├─ 向量/BM25 索引
   ├─ 本地 LLM 服务（llama.cpp / vLLM）
   └─ 反馈/审计/监控
```

【填写：客户现场的网络区域、谁能访问、是否跨网段、是否有反向代理。】

## 3. 数据流

1. 客户端发问题 → 网关鉴权 → RAG 服务。
2. 问题向量化 → BM25/向量召回 → RRF 融合 → 权限过滤 → 重排 → top-k。
3. 提示词拼装（系统约束 + 资料 + 引用要求）→ LLM 流式生成。
4. 引用映射 → SSE 返回 → 反馈/审计落盘。
5. 日志/指标/追踪异步采集。

【填写：每一步落在哪个进程/容器、超时、重试、降级。】

## 4. 信任边界

| 边界 | 信任什么 | 不信任什么 | 控制 |
|---|---|---|---|
| 公网/办公网 → 网关 | 网关签名身份 | 客户端自报 `X-User-ID` | SSO/OIDC、TLS、限流 |
| 网关 → RAG 服务 | 网关内网头 | 公网直连 | 网络策略、mTLS/内网 ACL |
| RAG → LLM | 本地模型服务 | 模型输出 | 引用/拒答/输出过滤 |
| RAG → 文档 | 索引内容 | 文档里的指令 | 提示注入防护、工具隔离 |
| 运维 → 主机 | 运维账号 | 共享账号 | 最小权限、审计 |
