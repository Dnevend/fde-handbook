## 怎么用这个包

1. 先读 `04-acceptance.md`，确认验收标准和未决问题。
2. 按 `02-deploy.md` 在目标环境安装；每一步都有预期输出。
3. 用 `03-operations.md` 做健康检查和备份演练。
4. 用 `05-training.md` 培训管理员/操作员/最终用户。
5. 把 `06-ai-usage-policy.md` 发给使用者，签字确认。
6. 校验 `MANIFEST.sha256`，再进入试运行。
