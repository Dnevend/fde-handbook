# 序

> **这一部分要回答的问题**：这本书写给谁，它想解决什么问题，以及你现有的经验值多少。

序章不涉及具体技术，只做三件事：说清 FDE 这个角色与你的经验之间的关系，画出一套离线知识库系统的完整部件图，交代本书的硬件基线、阅读路线和复现约定。读完这四节，你应该能判断这本书是否值得投入时间，并知道该从哪一节开始动手。

全书八部分排成一条交付链路（图 0-1）：先把原理讲到够用，再依次做选型、部署、量化、检索、评估、加速，最后交出去。每一部分都以上一部分留下的失败为起点——这也是后面每一章的引子都写成问题的原因。
