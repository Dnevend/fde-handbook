# 第六部分 评估与调优

> **这一部分要回答的问题**：承接第五部分：链路搭起来了，怎么知道它答得好不好？

五节是"造尺子 → 用尺子"的顺序（图 6-1）：先有测试集，才谈得上检索指标和生成指标；有了指标，消融实验才有意义；而归因是把数字落回具体故障的最后一步。
